TikTok Symphony is TikTok's AI creative platform. Use this app to generate, edit, extend, translate and dub videos, generate digital-avatar presentations, discover inspiration, monitor tasks and download finished assets in Blackbird workflows.

This documentation covers version **1.1.0**, with **30 actions and five events**.

## Before setting up

TikTok Symphony contains two API families with different permissions and account requirements:

| Features | Required developer permission | Account requirements |
| --- | --- | --- |
| Seedance generation, editing/extension, inspiration, balances and generation usage | **Symphony Seedance Video Generation** | Authorized TikTok One (TTO) account; eligible credits or linked BytePlus balance |
| Translation/dubbing, reviewed-script dubbing, avatars, voices and creative downloads | **Generative AI Tool → Video Generation** | Approved TikTok developer app and TikTok allowlisting for the relevant alpha APIs |

Approval for one API family does not establish access to the other. Add the creative-tools permission and obtain TikTok allowlisting before using the new actions. Reauthorize after a permission change. Model and payment eligibility still apply to Seedance.

### OAuth

1. Create or open your app in the [TikTok for Business developer portal](https://business-api.tiktok.com/portal/).
2. Request the permission for the features you will use. For dubbing and avatars, contact your TikTok representative for the relevant allowlist access.
3. Copy **App ID** and **App secret** from the developer app's Basic Information.
4. Register the exact Blackbird callback under **Advertiser redirect URLs** and save the settings. The observed EU-1 callback is:

   ```text
   https://eu-1.blackbird.io/api-rest/connections/AuthorizationCode
   ```

5. For a different Blackbird environment, register its actual callback: the decoded `redirect_uri` from the authorization URL generated by Blackbird. Match its complete path and capitalization. The bridge URL `https://bridge.blackbird.io/api/AuthorizationCode` is different from the EU-1 callback above.
6. For Seedance only, sign in to [Symphony Creative Studio](https://ads.tiktok.com/creative/creativestudio/home/) and find **TikTok One account ID** in the top-right account menu. Creative-tools connections do not require this redundant ID.

The app builds the authorization URL with the selected App ID, Blackbird callback and generated state. Do not paste TikTok's example authorization URL into Blackbird or replace the state. Secrets are excluded from that URL. Both OAuth options use server-side token exchange and long-term token mode; revoked authorization requires reconnection.

### Access token

Manual connections accept an externally issued token authorized for the chosen API family. The App secret, App ID and advertiser ID are not access tokens. Seedance manual connections also need the authorized TTO account ID; creative-tools manual connections need only the token.

## Connecting

1. Install TikTok Symphony **1.1.0**, then open **Apps → TikTok Symphony → Add Connection**.
2. Name the connection and select the appropriate method:

   | Connection method | Enter | Use for |
   | --- | --- | --- |
   | **Sign in with TikTok (OAuth)** | App ID, App secret, TikTok One account ID | Existing Seedance features |
   | **Creative tools sign-in (dubbing and avatars)** | App ID, App secret | Dubbing, avatars and voices |
   | **Access token (manual)** | Access token, TikTok One account ID | Seedance with an externally issued token |
   | **Creative tools access token (manual)** | Access token | Creative tools with an externally issued token |

3. For OAuth, start sign-in from Blackbird, authorize the developer app in TikTok, and allow the flow to return to Blackbird. The host may vary button labels or ordering.
4. Complete the connection flow. Validation performs a read-only request: recent Seedance tasks for TTO connections, or the voice catalogue for creative-tools connections. Validation does not generate content or prove entitlement to every individual endpoint.
5. Use **Get credit balance** for a Seedance check; use **Search voices** and **Search digital avatars** for creative-tools acceptance checks.

Existing connection group keys and all 16 existing actions are preserved. Existing Seedance connections can call creative endpoints only when their token has the additional permission and relevant allowlisting. A creative-tools-only connection cannot run Seedance actions without a TTO account ID; use a Seedance connection for those actions.

For redirect mismatch errors, register the exact callback from the failed authorization URL, save the registration and restart sign-in from Blackbird. For permission errors, check both developer permissions and TikTok allowlisting, then reauthorize. No secret or token needs to be supplied in chat.

## Actions

### Video generation

- **Generate video from text** creates a video from a prompt. Choose a payment method explicitly. The action returns a task ID so that generation can be monitored separately.
- **Generate video from images** animates a first-frame image and optionally a last-frame image. Supply publicly accessible HTTPS image URLs and an optional prompt.
- **Generate video from references** creates a video from a prompt and reference images, videos or audio clips. Reference limits depend on the selected model. Seedance 2.5 uses explicit reference mode; it does not infer editing or extension from the prompt.
- **Generate ad video** creates one to three videos from a brief and optional product images. Choose at most one inspiration source: **Template ID**, **Top ad ID** or **Inspiration video URL**. **Language** is required and applies to voiceover and on-screen text. Each output video creates its own task and consumes credits or tokens.

Generation is asynchronous. Save the returned task IDs, monitor their status and download results only after they succeed. Optional model, resolution and aspect-ratio suggestions reflect documented compatible configurations; they do not confirm account entitlement.

### Video editing

- **Edit video** creates an edited version of an existing video from a prompt. Requires **Seedance 2.5** and **BytePlus paid tokens**. Supply a public HTTPS MP4 or MOV source video URL. The action automatically applies the editing mode's required adaptive aspect ratio and automatic duration, then returns a generation task ID. The source video is preserved.
- **Extend video** generates a continuation of an existing video using **Seedance 2.5**. Choose bonus credits or paid tokens, subject to account eligibility. Optional duration accepts 4–30 seconds, or `-1` with paid tokens to let TikTok decide. TikTok permits at most two extensions per video.

To edit or extend a generated video, run **Get video task** to refresh its temporary URL and map **Video → Video URL** into **Source video URL**. Editing requires a 4–30 second source; extension requires a 2–30 second source.

### Video tasks

- **Get video task** retrieves the status, result URLs, error details and usage for a selected task. Use it to refresh an expired result URL while the task remains available.
- **Search video tasks** searches retained tasks in the connected TTO account. Filter by task IDs, status, task type and UTC creation dates. Leave **Maximum results** empty to retrieve all matching retained records.
- **Cancel or delete video tasks** cancels queued tasks or permanently deletes finished task records. Running tasks cannot be canceled. Check each returned result and its failure reason; individual items can fail even when the request succeeds.
- **Download generated video** returns a succeeded task's video as a native Blackbird file after refreshing its download URL.
- **Download generated videos** returns files for up to 100 task ID entries. Duplicate IDs produce one file, in first-requested order. Every requested task must exist and have succeeded; a missing or unfinished task fails the action rather than returning a partial result.
- **Download last frame** returns a generated video's last frame as a JPEG file. The task must have been created with **Return last frame** enabled using paid tokens.

Task inputs provide searchable suggestions for resources accessible through the connection. Download suggestions include succeeded tasks; last-frame suggestions require an available frame. Known IDs can also be entered or mapped directly.

### Creative inspiration

- **Search templates** finds curated video templates, with optional search text and industry filters. Map a returned **Template ID** into **Generate ad video** to use that template as inspiration.
- **Search top ads** finds high-performing creative examples, with optional search text, industry, region and objective filters. Results can include creative URLs, brand details and provider-supplied performance metrics. Map **Top ad ID** into **Generate ad video** to use an example as inspiration.

Template and top-ad suggestions show readable names and identifying details. Select only one inspiration source when generating an ad video; clear a conflicting source yourself before choosing another.

### Account

- **Get credit balance** retrieves available bonus credits and the linked BytePlus balance in USD, together with expiry or top-up information when supplied by TikTok. The USD balance is not a count of remaining generation tokens.

### Generation usage

- **Get generation usage** summarizes retained tasks by optional UTC creation dates and task type. Outputs include task counts by status, bonus credits used, paid tokens used and generated duration in seconds.

Usage is calculated from available generation task records. It covers at most seven days and excludes deleted records. It is not a billing statement or an organic video-performance report. Dates refer to task creation, rather than the date a charge was posted. If more than 1,000 tasks match, narrow the date range or task type to obtain a complete summary.

### Translation and dubbing

- **Translate and dub video** submits a public HTTP/HTTPS source video URL for automatic translation and dubbing into an explicitly selected target language. Optional settings select a voice, enable lip sync, display subtitles or name the video. The action returns creative task IDs. Omit Voice ID to preserve the original speaker voice, according to TikTok's documented behavior.
- **Dub video with reviewed subtitles** uses an approved UTF-8 SRT file instead of automatic translation. Select the SRT's target language explicitly. The app converts subtitle timing to milliseconds and sends the reviewed text and timing through TikTok's custom `scripts` input. It does not translate, infer the language, retime or paraphrase the approved text. SRT intervals must be non-negative and end after they start; TikTok checks timing against the source video's duration. Maximum input file size is 2 MiB.

Before either action's initial API call for each selected source video, collect the affirmative end-user acknowledgement required by TikTok's supplied Dubbed Translations specification. **Video consent confirmed** defaults to false and must be set true only after that acknowledgement has been collected for the selected video. Mapping a constant true is not a substitute for obtaining the acknowledgement. The complete notice is included in the field description and the technical guide. Live notice visibility and the surrounding end-user consent workflow require acceptance testing in Blackbird.

Each action creates one language variant. Use a workflow loop for multiple languages. The provider accepts 13 language codes: `ar`, `en`, `fr`, `de`, `id`, `it`, `ja`, `ko`, `pt`, `es`, `th`, `tr`, `vi`. There is no automatic English selection.

### Dubbing tasks and videos

- **Get dubbing task** retrieves the selected task's status, generated video ID, preview URL, subtitle URL and available error details. Map a creation task ID into this action.
- **Search dubbed videos** searches the finished videos returned for the authorized TikTok for Business account. Optional text and target-language filters are applied locally. The supplied endpoint contract has no pagination controls; the app does not invent them or promise historical completeness beyond the returned response.
- **Get dubbed video** retrieves a selected finished video's metadata and original/translated script segments. Choose a searchable **Dubbed video ID**, or enter/map one directly. A video ID differs from a task ID. If reviewed segments were supplied, TikTok may return them in both original and translated script collections; do not treat the original collection as an independent source transcript in that case.
- **Download dubbed video** returns a succeeded dubbing task's video as a native Blackbird file.
- **Download dubbed subtitles** returns its available SRT file as a native Blackbird file.

### Avatars and voices

- **Search digital avatars** finds currently available avatars by name, tags or ID, with an optional fixed avatar-type filter for AI-generated or real-person avatars. Outputs include provider tags, thumbnail and preview URLs.
- **Search voices** finds available voices by name, tags or ID and returns voice metadata and preview audio URLs.

Avatar and voice pickers use provider-backed catalogues from the selected connection. Names, tags and IDs are shown; manual/mapped IDs remain supported. Avatars and voices can be retired, so obtain current choices rather than treating old IDs as permanently valid. Tags do not establish a universal language-compatibility mapping; inspect the provider tags and validate voice suitability for your selected language. The app does not invent language-based entitlement checks.

### Digital avatar videos

- **Generate avatar video** creates a video of a selected avatar reading the supplied script. **Avatar ID**, **Script** and **Asset rights confirmed** are required. Scripts are limited to 2,000 characters. Optional inputs select a voice, voice volume (0–10, up to two decimal places), voice speed, transparent background and video name. Omitted voice settings follow TikTok defaults. Inspect the returned per-item error before mapping a task ID.
- **Get avatar task** retrieves a task's status, generated avatar video ID, preview URL, subtitle URL and available error details.
- **Search avatar videos** finds finished avatar videos with optional text, Avatar ID and inclusive UTC creation-date filters.
- **Download avatar video** returns a succeeded avatar task's video as a native Blackbird file.
- **Download avatar subtitles** returns its available SRT file as a native Blackbird file.

Creative task IDs are typed/mapped inputs because the documented contracts do not enumerate pending task IDs. Finished video catalogues contain video IDs, which are not substituted for task IDs. Map the task ID returned by the matching creation action.

## Events

### Individual video tasks

- **On video task finished** monitors one selected **Video task ID**. The first poll establishes a baseline. A later poll reports the task when it is **SUCCEEDED**, **FAILED**, **EXPIRED** or **CANCELLED**, once for the stored event memory. Check **Status** before downloading a result.

### Account-wide generation

- **On generated video ready** starts a separate Flight for each newly observed succeeded task in the connected TTO account.
- **On video generation failed** starts a separate Flight for each newly observed failed or expired task in that account. Canceled tasks are excluded.

Account-wide events need no account ID input. Their first poll records existing terminal tasks without starting Flights. Subsequent polls can recognize tasks that were already queued or running when monitoring began. Each Flight receives the task details, including status, available result URLs, errors and usage.

These events monitor Symphony generation tasks. They do not monitor videos published on TikTok profiles.

### Dubbing and avatar tasks

- **On dubbing task finished** monitors a mapped dubbing task ID and continues when the task reaches **SUCCESS** or **FAILED**.
- **On avatar task finished** does the same for a mapped avatar task ID.

The first poll establishes a baseline and starts no Flight. Later polls report the terminal result once for stored memory; task, task type or connection identity changes reset the baseline. Check Status before downloading. Provider errors preserve the previous memory. These are single-task events; each returns one task object. No webhook subscription is registered because none is documented for these v1.3 operations. Dubbing may take about an hour for a one-minute source video, according to the supplied guide, so use realistic polling intervals and allow sufficient workflow duration.

## Limitations

- **Seedance access and cost:** Seedance features use Symphony Seedance Video Generation authorization. Account/model eligibility still applies. Paid-token generation is documented for non-US advertisers; Seedance 2.5 bonus-credit access requires TikTok allowlisting. Editing requires paid tokens. Generation, editing and extension can incur charges.
- **Seedance task retention:** Only tasks created within the last seven days can be retrieved. Canceled task records are removed after 24 hours. Download and store finished assets promptly.
- **Seedance download links:** Video and last-frame URLs are valid for 24 hours. Download actions refresh them while the task is retained. Seedance 2.5 video download URLs are subject to TikTok's limit of 100 downloads.
- **Seedance source files:** Generation and transformation inputs require public HTTPS media URLs. The app does not upload private source files or make them public. Map a suitable URL from a storage workflow. TikTok validates media availability, format, dimensions and duration.
- **Seedance source video constraints:** Editing and extension accept MP4/MOV videos up to 200 MB, with dimensions of 300–6000 pixels, an aspect ratio of 0.4–2.5 and 24–60 fps. Other reference limits vary by model.
- **Payment-specific options:** Resolution, aspect ratio, audio generation, priority and last-frame settings depend on the action and payment method. Leave unsupported options empty. Resolution suggestions for editing/extension appear only after paid tokens are selected.
- **Language and inspiration:** Ad generation requires an explicit language. Supported choices are English, Spanish, Indonesian, Japanese, Korean, Portuguese and Simplified Chinese. Only one inspiration source may be selected.
- **Seedance dropdown searches:** Searches examine up to 10 pages of 100 records and return at most 100 matching suggestions. An incomplete or overly broad search produces an error. Refine the search, use the corresponding Search action, or enter/map an ID directly. Maintained model/configuration catalogues are not live permission checks.
- **Account monitoring:** Account-wide events request at most 11 pages per poll and fail without advancing memory if more than 1,000 tasks are available. Use **On video task finished** for individual tasks in higher-volume accounts.
- **Event batches:** Account-wide events emit at most 100 Flights per poll. Remaining matches stay eligible on subsequent polls while retained. Tasks deleted before a poll, or missed beyond the retention window, cannot be recovered.
- **Repeat delivery:** Resetting event memory or changing the monitored task/account can result in repeat delivery. Use **Video task ID** to prevent duplicate downstream processing.
- **Retries:** Generation and other write requests are not retried automatically. If acceptance is uncertain, inspect recent tasks before resubmitting to avoid duplicate generation and charges. Workflow-level retry settings can still resubmit an action.
- **OAuth removal:** Removing an OAuth-managed connection invokes remote token revocation and can affect other uses of that same token. Removing a manual-token connection does not remotely revoke its supplied token.
- **Scope:** This app does not publish organic posts, manage comments/campaigns, retrieve audience analytics, or manage subtitle tracks on already published TikTok posts. Generate/remix, legacy image animation and creative/GMV Max pre-review are separate future additions. The new dubbing/avatar workflows use the supplied v1.3 contracts; Seedance generation uses v2.0.
- **Validation status:** Version 1.1.0 builds successfully and its integration tests are discoverable. Live TikTok calls, browser OAuth acceptance, native file delivery and event persistence still require validation in the target Blackbird environment.

- **Creative access:** Dubbing and avatars require Generative AI Tool → Video Generation and TikTok allowlisting. These are alpha APIs in the supplied specifications. Access and cost are controlled by TikTok; the app does not infer that Seedance credits or balances apply to them.
- **Creative media:** Dubbing requires a publicly accessible HTTP/HTTPS video URL. The app does not upload or stage a private source video. TikTok recommends sources no longer than 300 seconds and no larger than 200 MB. Silent videos with supplied scripts are not supported by the documented dubbing workflow.
- **Creative expiry:** Creative video preview URLs last 180 days; subtitle URLs last seven days. Re-querying does not renew those URLs. Expired outputs require a new generation task; save files promptly. Avatar thumbnails/demo previews expire after six hours.
- **Creative searches:** Avatar/voice scans are bounded to 50 pages of 100 entries and dropdowns to 100 matching choices, with explicit incomplete/too-broad errors. Dubbed-video responses over 5,000 entries fail with guidance to use a known task ID. No undocumented pagination is added.
- **Creative quotas:** Supplied limits are 100 requests/minute shared between remix and dubbing creation, and 20/minute for avatar creation, with daily caps. These are provider/developer-app quotas shared with other clients; no local process can establish remaining global quota. Rate-limit errors are surfaced, and creation is not automatically retried.
- **Localization boundaries:** Lip sync has source-media constraints and is unsuitable for overlapping speech or occluded mouths. Source transcription before starting a dubbing job is not a verified standalone operation in this contract. Reviewed-SRT input must already contain approved target-language text and timing.
